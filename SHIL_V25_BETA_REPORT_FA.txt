SHIL V25 - Consumer Bank Restore + Beta Preparation
===================================================

تغییرات اصلی:
- بانک پایه 250 مصرف‌کننده دوباره به عنوان Baseline فعال شد.
- داده Runtime/Supabase دیگر کل بانک پایه را جایگزین نمی‌کند؛ روی Baseline merge می‌شود.
- رکورد Cloud با ID یکسان، رکورد پایه را override می‌کند.
- رکورد Cloud جدید با ID جدید، به بانک پایه اضافه می‌شود.
- در مسیر کاربر فقط Active + Published نمایش داده می‌شود.
- در کارتابل ادمین تمام رکوردها قابل مدیریت‌اند.
- هنگام ورود ادمین، اگر Cloud فقط بخشی از بانک را داشته باشد، Baseline کامل با رکوردهای Cloud ادغام و برای Cloud ثبت می‌شود.
- محدودیت slice(0, 250) در مسیر اصلی وجود ندارد؛ شمارنده از طول واقعی بانک می‌آید.
- ابزار consumer:check برای کنترل معماری بانک اضافه شد.
- دستور beta:release و PREPARE_BETA.ps1 برای آماده‌سازی تست اضافه شد.
- TESTER_CHECKLIST_FA.txt برای تست سیستماتیک اضافه شد.

نکته:
رکوردهای تست قبلی Cloud عمداً حذف نشده‌اند تا داده کاربر بدون اجازه از بین نرود.
