SHIL V25.4 - Admin Engineering Path Defaults

- دو کارت اصلی برای پیش فرض مسیر خورشیدی و برق اضطراری اضافه شد.
- هر مسیر شامل 8 مرحله مطابق projectWorkflow واقعی اپ است: مسیر پروژه، اطلاعات پروژه، شرایط محیطی، روش ورود دیتا، ورودی محاسبات، تنظیمات، چکیده طراحی، اجرا.
- کارت های مراحل Mobile-first، دو ستونه، مینیمال و پیش فرض بسته هستند.
- جزئیات هر مرحله فقط داخل Accordion نمایش داده می شود.
- تمام بلوک های داخلی با عنوان «پیش فرض های ...» مشخص شده اند.
- رنگ های این مجموعه فقط طیف آبی آسمانی/سفید است و بنفش استفاده نشده است.
- والدهای بزرگ و گپ های اضافی برای این مجموعه استفاده نشده اند تا بک گراند اپ دیده شود.
- تنظیمات واقعی موجود در موتور در مرحله مرتبط نمایش داده می شوند؛ مراحل بدون پارامتر مستقل فقط توضیح وضعیت دارند و مقدار ساختگی ایجاد نشده است.
- برق اضطراری: ساعت مبنای بارها 1 ساعت؛ زمان پیش فرض 3 ساعت؛ محدوده قابل تنظیم 1 تا 24 ساعت.
- saveAdminDefaults اکنون admin_defaults را در Runtime App Data نیز Sync می کند تا انتشار ادمین به پروژه های کاربران برسد.
- سه اقدام: ذخیره پیش نویس، انتشار برای کاربران، بازگردانی کارخانه.
