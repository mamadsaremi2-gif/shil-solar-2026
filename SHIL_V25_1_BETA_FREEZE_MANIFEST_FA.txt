SHIL V25.1 BETA FREEZE
تاریخ فریز: 2026-08-16

وضعیت مبنا:
- آماده‌سازی Beta تا مرحله 7/7 روی سیستم توسعه‌دهنده پاس شده است.
- تست Smoke Engine پس از سازگار کردن backendConfig با Vite و Node پاس شده است.
- بانک مصرف‌کننده/تجهیزات از منبع پویا استفاده می‌کند و محدودیت نمایشی ثابت 250 حذف شده است.
- ساختار Admin UI بر مبنای V24 Clean Consolidated نگه داشته شده است.
- Supabase/Runtime Data مسیر اصلی داده پویا است.

اصلاح تثبیت‌شده در این Freeze:
- src/backend/config/backendConfig.js برای اجرای امن در Vite و Node سازگار شد.
- هیچ تغییر جدیدی در فرمول‌های مهندسی، RLS، احراز هویت یا منطق پروژه اعمال نشده است.

قانون نسخه:
- این بسته مرجع سالم Beta است.
- هر اصلاح بعدی باید با شماره نسخه جدید (V25.2 و بالاتر) انجام شود.
- قبل از تست کاربران واقعی، از تغییرات معماری یا UI گسترده خودداری شود.

تست پیشنهادی قبل از ارسال:
1) npm ci
2) powershell -ExecutionPolicy Bypass -File .\PREPARE_BETA.ps1
3) تست ورود کاربر و ادمین
4) تست پروژه خورشیدی و برق اضطراری
5) تست افزودن تجهیز از Admin و مشاهده آن در مسیر کاربر بعد از Refresh
6) تست PWA/Install و خروجی نهایی پروژه
