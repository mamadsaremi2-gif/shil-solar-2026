# SHIL Project Info V13.1 Hard Layout

- ساختار سه کارت اطلاعات پروژه از Grid عمومی پروژه جدا شد.
- نام پروژه و نام کارفرما در یک ردیف Flex مستقل و برابر قرار گرفتند.
- تاریخ ثبت در ردیف Flex مستقل دوم قرار گرفت و دقیقاً هم‌اندازه یک کارت ردیف بالا شد.
- کارت تاریخ همیشه با `justify-content:center` مرکزچین است و دیگر هیچ `grid-column` یا `:last-child` قدیمی روی آن اثر ندارد.
- عنوان‌های «مشخصات اولیه پروژه» و «توضیحات پروژه» با همان زبان بصری روشن کارت‌ها نمایش داده می‌شوند.
- این Component مشترک است و برای هر دو مسیر خورشیدی و برق اضطراری اعمال می‌شود.
- منطق داده، پیش‌فرض `کاربر` و `SHIL CO` و سایر محاسبات تغییر نکرده‌اند.
