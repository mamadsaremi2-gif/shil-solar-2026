# گزارش اصلاح UI حفاظت اجرای نهایی - V7

تاریخ: 1405/05/17

## اصلاحات
- مرکزچین شدن عنوان هر گروه حفاظت در موبایل و حذف ستون کناری نامتوازن.
- مرکزچین شدن مجموعه آکاردئون‌های حفاظتی داخل کارت والد.
- محدود شدن عرض summary و detail به 100% والد و جلوگیری از overflow افقی.
- شکستن خودکار متن‌های لاتین طولانی داخل سلول‌ها.
- مرکزچین شدن جدول دیتاشیت بازشونده.
- افزایش خوانایی با تفکیک رنگی ستون عنوان و مقدار.
- اعمال zebra rows برای تشخیص سریع سطرهای جدول.
- حفظ ساختار خلاصه بسته: جریان / پل / تعداد.
- بدون تغییر در موتور محاسبات، Header/Footer، فونت و زبان اپ.
