# گزارش اصلاح V5.32 — حفظ کامل داده‌ها هنگام بازگشت

## علت ایراد V5.31
در نسخه قبلی، ذخیره Draft مسیر قبلی داخل useEffect تغییر Route انجام می‌شد. در زمان اجرای Effect، React ممکن بود صفحه جدید را جایگزین کرده باشد؛ بنابراین DOM صفحه جدید با کلید صفحه قبلی ذخیره و Draft قبلی خراب می‌شد.

همچنین صفحه انتخاب مسیر از محدوده ذخیره وضعیت خارج شده بود.

## اصلاحات
- کل جریان /new-project شامل صفحه انتخاب مسیر وارد محدوده نگهداری وضعیت شد.
- ذخیره DOM صفحه فعلی پیش از اجرای handlerهای React و پیش از Navigate، به‌صورت synchronous در capture phase انجام می‌شود.
- ذخیره اشتباه صفحه قبلی پس از commit شدن صفحه جدید حذف شد.
- برای Back مرورگر و gesture بازگشت موبایل، ذخیره روی popstate اضافه شد.
- ذخیره هنگام pagehide، beforeunload، input، change و انتخاب کارت حفظ شد.
- بازیابی چندمرحله‌ای تا 1200ms برای صفحات lazy و controlled inputs انجام می‌شود.
- هیچ MutationObserver جدیدی اضافه نشده است.

## نتیجه مورد انتظار
کاربر می‌تواند از صفحه اجرا و خروجی نهایی تا صفحه انتخاب مسیر پروژه بازگردد و اطلاعات، انتخاب‌ها و ورودی‌های همان پروژه باقی بمانند. پس از اصلاح و تأیید دوباره، ادامه مسیر با داده‌های جدید انجام می‌شود.
