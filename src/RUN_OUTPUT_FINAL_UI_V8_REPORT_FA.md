- حفظ کامل منطق محاسبات Protection Engine V4 و چیدمان تأییدشده V7.
- افزودن اختلاف رنگ ملایم بین ردیف‌های تجهیزات حفاظتی در صفحه اجرای نهایی.
- ایجاد حس برجستگی برای سلول‌های خلاصه جریان / پل / تعداد با Border و Shadow بسیار سبک.
