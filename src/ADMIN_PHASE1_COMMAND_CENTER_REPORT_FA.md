# گزارش Admin Phase 1 — Engineering Command Center

نسخه: `SHIL_ADMIN_SYSTEM_110_PHASE1`

## تغییرات اجراشده
- بازطراحی نمای کلی درگاه ادمین به Command Center فشرده و Mobile-first.
- KPIهای واقعی بر پایه داده‌های موجود: سلامت، کاربران، پروژه‌ها، پروژه‌های نهایی، تجهیزات فعال و پیام‌های باز.
- جستجوی سراسری بین کاربران، پروژه‌ها، پنل‌ها، اینورترها و باتری‌ها.
- نمایش سلامت سرویس‌های موتور، Supabase، Storage/PWA و بانک تجهیزات بدون جعل وضعیت آنلاین سرویس‌های فاقد Probe واقعی.
- مرکز اعلان برای هشدارهای Validation، پیام‌های باز و حالت Local/Supabase.
- Quick Actions برای پروژه‌ها، کاربران، تجهیزات، تنظیمات مهندسی، Cloud و Snapshot.
- Activity Timeline ترکیبی از Audit Log ادمین و آخرین تغییرات پروژه‌ها.
- بخش Version/Data برای ردیابی نسخه Admin/Engine، تعداد تجهیزات و منبع داده.
- هماهنگ‌سازی ظاهر با Design System مهندسی SHIL و حذف وابستگی نمای جدید به رنگ بنفش.

## نکته معماری
در این فاز فقط قابلیت‌هایی که داده واقعی برایشان در نسخه موجود وجود دارد نمایش داده شده‌اند. «کاربر آنلاین»، latency API، Error Rate و Queue واقعی تا زمان اضافه شدن telemetry/server probe به شکل عدد ساختگی نمایش داده نمی‌شوند.
