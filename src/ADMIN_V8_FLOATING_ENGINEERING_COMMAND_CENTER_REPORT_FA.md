# SHIL Admin V8 — Floating Engineering Command Center

این بازسازی فقط لایه نمایشی صفحات ادمین را هدف قرار می‌دهد و منطق احراز هویت، PIN، داده‌های فارسی، Supabase، Review، Equipment CMS، Rule Engine، Analytics و Diagnostics دست‌نخورده باقی مانده‌اند.

## تغییرات اصلی
- حذف کامل سطح بصری والدهای بزرگ ادمین؛ Wrapperهای React برای حفظ منطق DOM باقی مانده‌اند اما شفاف هستند.
- نمایش مستقیم تصویر پس‌زمینه خورشیدی بین کارت‌ها و سکشن‌ها.
- تبدیل عنوان هر سکشن به کارت مستقل و کم‌ارتفاع.
- کارت‌های KPI، سرویس‌ها، اعلان‌ها، Quick Action، Timeline، Review، CMS، Release و Diagnostics به سطوح مستقل Floating تبدیل شدند.
- Mobile-first: فاصله 7–8px از کناره‌ها، فاصله 5–7px بین کارت‌ها و ارتفاع‌های فشرده.
- حذف هرگونه وابستگی بصری به رنگ بنفش در لایه جدید؛ پالت روشن سفید/آبی/فیروزه‌ای مهندسی.
- رفع overflow نسخه‌های طولانی و مقادیر انگلیسی با `overflow-wrap` و حفظ `dir=ltr`.
- حفظ RTL فارسی و `unicode-bidi` برای خطوط ترکیبی فارسی/انگلیسی.
- Header و Footer دست‌نخورده و مطابق Design System موجود باقی مانده‌اند.

## ایمنی تغییر
فایل اصلی `AdminDashboard.jsx` تغییر منطقی نکرده است. تنها یک CSS ادمین‌محور در انتهای `main.jsx` import شده تا روی سایر صفحات پروژه اثری نداشته باشد.
