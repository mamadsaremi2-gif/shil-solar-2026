# گزارش تغییرات V6.1 صفحه شرایط محیطی

## انجام‌شده

- بازطراحی زیرمجموعه «یک جهت / چند جهت» بدون تغییر موتور محاسبات.
- تبدیل آرایه‌های چندجهته به کارت‌های جمع‌شونده (Accordion).
- باز بودن فقط یک آرایه در هر لحظه برای کاهش طول صفحه.
- نمایش خلاصه جهت، زاویه و راندمان در حالت بسته هر کارت.
- انتقال دکمه حذف به هدر فشرده کارت.
- حذف فاصله‌های اضافه میان عنوان، فیلد، راهنما و نتیجه.
- یکدست‌سازی رنگ‌ها با پالت بنفش، سفید و آبی روشن.
- یکدست‌سازی ارتفاع فیلدها، شعاع گوشه‌ها و حاشیه‌ها.
- تبدیل نتایج افت جهت، افت زاویه و راندمان به ردیف خلاصه فشرده.
- ساخت کارت خلاصه نهایی راندمان محیطی برای هر دو حالت تک‌جهته و چندجهته.
- حفظ منطق فعلی ذخیره‌سازی، محاسبات، روش طراحی و پروژه‌های قبلی.
