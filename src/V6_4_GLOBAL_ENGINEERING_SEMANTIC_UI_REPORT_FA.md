# گزارش نسخه V6.4 — سیستم رنگ معنایی تمام صفحات مهندسی

این نسخه زبان بصری واحد را از صفحه انتخاب مسیر پروژه تا اجرای نهایی اعمال می‌کند.

- آبی روشن: داده ثابت، مرجع، راهنما و مقادیر فقط‌خواندنی
- سبز روشن: فیلدها و داده‌های قابل تکمیل توسط کاربر
- قرمز روشن: پاسخ‌ها، نتایج محاسباتی و خروجی موتور
- بنفش: انتخاب فعال، افزودن و تأیید مرحله
- قرمز هشدار: حذف و هشدارها

صفحات تحت پوشش:

1. انتخاب مسیر پروژه
2. اطلاعات پروژه
3. شرایط محیطی و آرایه‌های نصب
4. روش طراحی
5. ورودی محاسبات
6. تنظیمات سیستم
7. چکیده
8. اجرا و خروجی نهایی

همچنین لایه‌های رنگی اضافی پشت کارت‌ها حذف شده و کارت‌ها روی بک‌گراند اصلی قرار گرفته‌اند. منطق محاسبات، ذخیره‌سازی و مسیرهای برنامه تغییر نکرده است.
