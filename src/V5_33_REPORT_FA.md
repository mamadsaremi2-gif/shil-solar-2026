# گزارش V5.33

در این نسخه سه صفحه‌ای که هنوز با بازگشت اطلاعاتشان پاک می‌شد، به صورت مستقیم در سطح State خود کامپوننت اصلاح شدند:

- ورودی محاسبات
- شرایط محیطی
- مسیر پروژه

## علت اصلی
بازیابی عمومی DOM برای فیلدهای Controlled React کافی نبود؛ پس از بازیابی ظاهری، رندر React دوباره مقدار State اولیه را روی صفحه اعمال می‌کرد.

## اصلاح
- State کامل ورودی محاسبات به تفکیک پروژه، دامنه و روش محاسبه ذخیره و در Mount بعدی بازیابی می‌شود.
- اطلاعات شرایط محیطی مستقیماً از environmentDraft مقداردهی اولیه و همزمان ذخیره می‌شود.
- انتخاب مسیر پروژه از projectPath و selectedProjectPath بازیابی می‌شود و با انتخاب کاربر بلافاصله ذخیره می‌گردد.
- داده‌ها هنگام بازگشت از صفحه اجرا تا اولین صفحه مسیر پروژه باقی می‌مانند.
