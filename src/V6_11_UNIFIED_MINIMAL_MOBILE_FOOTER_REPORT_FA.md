# گزارش V6.11 — یکپارچه‌سازی فوتر مینیمال موبایل

## هدف
کاهش ارتفاع فوتر، کوچک‌کردن دکمه‌ها، حذف نوار سفید پایین صفحه در آیفون و یکسان‌سازی فوتر در تمام صفحات اپ.

## مقادیر نهایی موبایل
- ارتفاع ردیف اصلی فوتر: 56px
- فضای Safe Area: به‌صورت خودکار با `env(safe-area-inset-bottom)`
- ارتفاع دکمه‌ها: 42px
- فاصله دکمه‌ها: 6px
- Padding افقی فوتر: 10px
- اندازه متن: 12px
- در عرض کمتر از 380px: متن 11px و فاصله 4px

## تغییرات
1. ایجاد فایل نهایی `shil-mobile-footer-minimal-v6-11-final.css`.
2. Import فایل به‌عنوان آخرین CSS در `main.jsx`.
3. اعمال یک ساختار مشترک برای `.shil-fixed-footer` و `.shil-footer` در همه صفحات.
4. تنظیم پس‌زمینه `html` و `body` برای جلوگیری از نمایش نوار سفید خارج از Root در Safari و حالت Home Screen آیفون.
5. اصلاح Padding پایین Scroll View متناسب با ارتفاع جدید فوتر.

## محدوده اثر
- مسیر پروژه
- اطلاعات پروژه
- شرایط محیطی
- روش طراحی
- ورودی محاسبات
- تنظیمات خورشیدی و برق اضطراری
- چکیده و خروجی
- سایر صفحات عمومی که از فوتر مشترک استفاده می‌کنند

نسخه دسکتاپ در این تغییر دست‌نخورده باقی مانده است.
