# SHIL Admin V10 — Two Column Module Hub

این نسخه فقط لایه رابط کاربری Admin را تغییر می‌دهد و منطق مهندسی، صفحات کاربر، محاسبات، ورود Hybrid، Supabase و RTL فارسی دست‌نخورده مانده‌اند.

تغییرات اصلی:
- صفحه اول کارتابل به Hub دو ستونه و Mobile-first تبدیل شد.
- والد خاکستری ناوبری حذف شد؛ کارت‌های مستقل مستقیماً روی تصویر پس‌زمینه قرار می‌گیرند.
- ماژول‌های مرتبط در ۸ کارت مادر گروه‌بندی شدند و زیرمجموعه‌ها در صفحه بعدی همان گروه نمایش داده می‌شوند.
- فاصله کناری و فاصله کارت‌ها به ۴ تا ۵ پیکسل کاهش یافت.
- ارتفاع کارت‌های Hub روی موبایل ۵۸ پیکسل و فونت‌ها فشرده‌تر شدند.
- رنگ کارت‌ها به گرادیان سفید مایل به آبی آسمانی تغییر کرد.
- برای گروه‌های چندبخشی، Child Tabs کم‌ارتفاع اضافه شد.
- دکمه بازگشت به بخش‌ها برای برگشت سریع به Hub اضافه شد.
- استایل V10 کاملاً با `.shil-page--admin` Scope شده و روی صفحات مهندسی دیگر اثر نمی‌گذارد.
