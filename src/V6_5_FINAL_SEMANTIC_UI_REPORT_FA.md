# گزارش نسخه V6.5 نهایی رابط مهندسی

در این نسخه یک لایه CSS نهایی و سراسری پس از تمام استایل‌های قدیمی بارگذاری شده است.

## قانون رنگ
- آبی روشن: اطلاعات ثابت، مرجع و فقط‌خواندنی
- سبز روشن: ورودی یا انتخاب قابل تغییر توسط کاربر
- قرمز روشن: نتیجه محاسبه، خروجی موتور و اطلاعات نهایی
- بنفش/آبی: اکشن اصلی و انتخاب فعال
- زرد روشن: هشدار

## قانون خطوط
تمام کادرها، فیلدها، دکمه‌ها، کارت‌ها، جداول و جداکننده‌های صفحات مهندسی با خط مشکی یکدست شده‌اند.

## پوشش صفحات
- مسیر پروژه
- اطلاعات پروژه
- شرایط محیطی و تمام فرزندان آن
- روش طراحی
- ورودی محاسبات و تمام حالت‌ها
- تنظیمات و بانک تجهیزات
- چکیده طراحی
- اجرا و خروجی نهایی

منطق محاسبات، ذخیره‌سازی و مسیرهای برنامه تغییر نکرده‌اند.
