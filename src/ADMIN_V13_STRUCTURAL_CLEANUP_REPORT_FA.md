# گزارش SHIL ADMIN V13 — پاک‌سازی ساختاری کارتابل ادمین

تاریخ: 2026-08-10

## هدف
اصلاح ساختار کارتابل ادمین بر اساس بازخورد مستقیم تصویری/DevTools و نزدیک‌کردن جریان صفحه به زبان بصری صفحه چکیده مهندسی، بدون تغییر منطق داده و عملکرد زیرصفحه‌های ادمین.

## تغییرات اصلی

1. «خروج از کارتابل ادمین» از بالای صفحه حذف و به انتهای واقعی محتوای ادمین منتقل شد.
   - ارتفاع کم: حدود 32 تا 34px در موبایل.
   - عرض متوسط: حدود 46 تا 48 درصد با سقف 220px.
   - هم‌خانواده با دکمه‌های تأیید معمولی.

2. «مرکز مدیریت SHIL» به اولین ردیف زیر Header تبدیل شد.
   - ارتفاع 36 تا 38px.
   - یک ردیف مستقل و کم‌ارتفاع.
   - بدون لایه/والد اضافه.

3. «بازگشت به بخش‌ها» در Section View به دومین دیتای واقعی بعد از عنوان مدیریت منتقل شد.
   - چند پیکسل کوچک‌تر از Title Row.
   - از حالت کارت بزرگ و عمودی خارج شد.

4. بنر بزرگ «نمای کلی و پایش» در صفحه Monitoring حذف شد.
   - دسترسی به «نمای کلی» و «تحلیل و پایش» حفظ شده و به Tabهای فشرده تبدیل شده است.
   - هیچ قابلیت Dashboard/Analytics حذف نشده است.

5. کارت‌های دو ستونه Hub کوتاه شدند.
   - فقط عنوان اصلی کوتاه روی سطح اصلی کارت دیده می‌شود.
   - توضیحات طولانی از سطح اصلی حذف شد.
   - توضیحات هر کارت در یک Accordion بسیار مینیمال با عنوان «جزئیات» داخل همان کارت قرار گرفت.

6. عناوین Hub کوتاه‌سازی شدند:
   - نمای کلی
   - بررسی مهندسی
   - کاربران
   - پروژه‌ها
   - تجهیزات
   - قوانین
   - امنیت
   - خطا و سرویس‌ها

## اصلاح مهم Parent بزرگ گزارش‌شده در DevTools

در تصویر DevTools مشخص شد عنصر زیر:

`<section class="shil-admin-module-hub-v10">`

توسط قانون عمومی قدیمی پروژه هدف قرار می‌گرفت:

`body:not(.login-page):not(.welcome-page) section, article, div[class*="card"], ...`

و در نتیجه یک Matte/Glass parent بزرگ با blur/background به کل Hub تحمیل می‌شد.

### رفع V13

- تگ Hub از `section` به `div` تغییر کرد تا selector عمومی `section` دیگر آن را نگیرد.
- Hub با specificity بالاتر و import نهایی به صورت کامل reset شد:
  - background: transparent
  - border: 0
  - box-shadow: none
  - backdrop-filter: none
  - padding: 0
- pseudo-elementهای `::before` و `::after` نیز حذف شدند.
- خود کارت‌های دو ستونه surface واقعی هستند و Parent هیچ سطح بصری ندارد.

## فایل جدید

`src/appearance/styles/shil-admin-v13-structural-cleanup-final.css`

این فایل به عنوان آخرین import در `src/main.jsx` قرار گرفت تا قوانین قدیمی با `!important` نتوانند ساختار V13 را Override کنند.

## فایل JSX اصلاح‌شده

`src/pages/AdminDashboard.jsx`

اصلاحات ساختاری Hub، Navigation، Accordion توضیحات و Logout در JSX انجام شده‌اند؛ فقط CSS Override نیست.

## نکته Build

بسته پروژه تحویلی همچنان فاقد `package.json` است؛ بنابراین Build کامل npm در همین بسته قابل اجرا نیست. تغییرات V13 محدود به JSX/CSS و بدون Dependency جدید هستند.
