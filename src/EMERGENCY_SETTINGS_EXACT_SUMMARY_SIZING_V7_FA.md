# اصلاح دقیق ابعاد صفحه تنظیمات برق اضطراری - V7

- حذف ابعاد بزرگ قبلی کارت‌ها از خود کامپوننت صفحه تنظیمات.
- تطبیق کارت‌های نتیجه با صفحه چکیده: حداقل ارتفاع 56px، padding برابر 7px 8px، gap برابر 4px، radius برابر 11px.
- عنوان کارت 11px و مقدار 12px شد.
- ورودی‌های قابل ویرایش به ارتفاع 30px و فونت 12px کاهش یافتند.
- کارت‌های ورودی به دلیل وجود input و توضیح کوتاه، فقط 72px هستند و فضای اضافه حذف شده است.
- تمام قواعد اختصاصی با selector دقیق و !important اعمال شدند تا CSS عمومی اپ نتواند دوباره اندازه‌ها را بزرگ کند.
- کارت انتخاب تجهیزات و دکمه‌های جزئیات نیز هم‌اندازه و جمع‌وجور شدند.
