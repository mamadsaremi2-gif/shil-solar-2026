# گزارش بروزرسانی Phase 1.3 - شفافیت بانک و محاسبات تجهیزات

- نام گذاری مبهم مدل های تکراری بانک مصرف کننده حذف شد و هر رکورد با واریانت معنادار و توان نامی نمایش داده می شود.
- واریانت های استاندارد، پرتوان، سنگین، کم مصرف و صنعتی جایگزین شماره گذاری مدل ها شدند.
- برای هر تجهیز انتخاب شده یک آکاردئون «ریز محاسبات این تجهیز» اضافه شد.
- توان نامی، تعداد، توان مجموع، ضریب همزمانی، توان موثر، PF، راندمان مرجع، ولتاژ/فاز، جریان نامی، جریان کارکرد، ضریب استارت، جریان استارت، توان پیک، ساعت مصرف و انرژی روزانه نمایش داده می شود.
- فرمول ها با اعداد واقعی همان تجهیز نمایش داده می شوند تا نتایج نهایی کاملا قابل ردیابی باشند.
- جمع کل صفحه همچنان از همان selectedItems نرمال شده موتور محاسبات ساخته می شود.
- راندمان بانک فعلی 100 درصد و صرفا مرجع است؛ چون توان بانک به عنوان توان ورودی الکتریکی ثبت شده و برای جلوگیری از دوباره شماری، راندمان جداگانه روی بار اعمال نشده است.
- این تغییر برای هر دو مسیر خورشیدی و برق اضطراری قابل استفاده است.
