# گزارش SHIL Admin V9

این نسخه فقط لایه ادمین را تغییر می‌دهد و به صفحات مهندسی، موتور محاسبات، Auth، Supabase، مسیرهای پروژه و متن‌های فارسی خارج از ادمین دست نمی‌زند.

تغییرات:
- حذف pseudo-overlay عمومی صفحه ادمین که هنوز به شکل والد خاکستری روی تصویر خورشیدی دیده می‌شد.
- شفاف‌سازی کامل wrapperهای layout ادمین؛ فقط خود کارت‌های واقعی سطح روشن دارند.
- کاهش محسوس ارتفاع کارت‌ها، KPIها، تب‌ها، Search و Quick Actions برای Mobile-first.
- تبدیل `AdminPanel` به آکاردئون واقعی؛ توضیحات و داده‌های طولانی فقط با باز کردن همان سکشن نمایش داده می‌شوند.
- کاهش gap و paddingهای خالی برای کاهش Scroll.
- حفظ RTL فارسی و isolate کردن مقادیر LTR مهندسی/انگلیسی.
- حفظ Header/Footer ثابت و پس‌زمینه خورشیدی موجود.
