# گزارش بازگردانی اضطراری ظاهر SHIL

## علت
فایل `shil-engineering-design-system-v8-clean.css` با انتخابگرهای سراسری، ساختار صفحات ورود، خوش‌آمد، داشبورد و منوی موبایل را نیز تحت تاثیر قرار داده بود. در نتیجه تصاویر و کارت‌های ناوبری در اندازه بسیار بزرگ نمایش داده شدند.

## اقدام انجام‌شده
- ورودی `main.jsx` به زنجیره استایل پایدار V7 بازگردانده شد.
- import تم محلی `shil-engineering-theme-v2.css` در `App.jsx` بازگردانده شد.
- فایل V8 حذف نشده، اما دیگر در Runtime بارگذاری نمی‌شود.
- هیچ فایل منطق محاسباتی یا داده‌ای تغییر نکرد.

## روش جایگزینی
پوشه `src` این بسته را جایگزین پوشه `src` فعلی کنید، سپس:

```bash
npm run dev
npm run build
```
