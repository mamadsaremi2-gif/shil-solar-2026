# گزارش آپدیت UI صفحه اجرا و خروجی نهایی — Protection UI V5

تاریخ: 2026-08-08

## هدف
این آپدیت فقط لایه نمایش صفحه «اجرا و خروجی نهایی» را روی Protection Engine V4 اصلاح می‌کند. Header، Footer، فونت، زبان فارسی، رنگ‌بندی و اسکلت اصلی صفحات تغییر داده نشده‌اند.

## اصلاحات انجام‌شده
- خروجی حفاظت PV/DC، باتری و AC به جای رشته‌های بلند، به ردیف‌های مهندسی کوچک و خوانا تقسیم شد.
- برای تجهیزات حفاظتی نوع تجهیز، مدل/عنوان SHIL، تعداد، پل، Icu و استاندارد (در صورت وجود) نمایش داده می‌شود.
- حفاظت PV/DC در مسیر خورشیدی مستقیماً از `protection.pvDc` موتور V4 خوانده می‌شود.
- در مسیر برق اضطراری، بلوک PV/DC و کابل PV نمایش داده نمی‌شود.
- کابل‌های PV، باتری و AC از `cables/cableDetails` موتور خوانده می‌شوند.
- عبارت داخلی «خروجی مستقیم موتور مرکزی» حذف شد.
- در نبود اطلاعات کافی کابل، پیام کاربرپسند «نیازمند تعیین مشخصات مسیر اجرا» و درخواست ثبت طول/شرایط نصب نمایش داده می‌شود.
- پیام‌های توسعه‌دهنده شامل `src/engineering`، `Legacy` و پیام‌های داخلی اتصال موتور از بخش نتایج و هشدارها فیلتر شدند.
- کارت هشدارها به عنوان کوتاه + متن پیام تفکیک شد.
- فرم A4/PDF نیز برای حفاظت‌های ساختاریافته به Mini-row فشرده تغییر کرد تا اطلاعات مهندسی خواناتر بماند.
- مسیر برق اضطراری نیز اکنون از همان `buildProtectionRows` واحد استفاده می‌کند تا نمایش حفاظت در هر دو مسیر یک Source of Truth داشته باشد.
