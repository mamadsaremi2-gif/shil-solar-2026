# گزارش اصلاح صفحه اجرا و خروجی نهایی V12

## دامنه تغییر
این نسخه روی مسیر فعال `src/pages/project/RunCalculation.jsx` برای هر دو مسیر خورشیدی و برق اضطراری اعمال شده است.

## تغییرات معماری و داده
- UI موبایل از فرم A4 جدا شد. فرم A4 همچنان منبع واحد PDF/PNG/Share است اما دیگر به‌عنوان رابط اصلی موبایل نمایش داده نمی‌شود.
- در Solar نتیجه `runEngineeringDesign` در مرحله نهایی اجرا می‌شود و تجهیزات، حفاظت و کابل‌ها از خروجی موتور مرکزی خوانده می‌شوند.
- بازسازی محلی حفاظت Solar بر اساس تعداد MPPT/اینورتر حذف شد؛ بلوک حفاظت فقط داده‌های `protection`، `cables` و `cableDetails` موتور مرکزی را نمایش می‌دهد.
- زنجیره Backup Hours برق اضطراری اصلاح شد: مقدار هدف فقط از طراحی تأییدشده و handoff/ورودی ثبت‌شده خوانده می‌شود و دیگر runtime واقعی باتری به‌عنوان fallback زمان هدف استفاده نمی‌شود.
- تبدیل واقعی اعداد فارسی/عربی به انگلیسی تکمیل شد.
- همه اعداد نمایشی مهندسی به حداکثر دو رقم اعشار محدود شدند.
- واحدهای مهندسی با حروف بزرگ و قبل از مقدار نمایش داده می‌شوند، مانند `W 2200`، `KWH 8.97`، `V 220` و `H 3`.

## تغییرات UI
- بلوک‌های 01 تا 04 به کارت‌های Native و خوانای موبایل تبدیل شدند.
- بلوک 04 حفاظت و الزامات اجرا از همان Header، Border، Radius، Gap و سیستم چیدمان بلوک‌های 02 و 03 استفاده می‌کند.
- کارت‌های «نتایج و هشدارها» و «خروجی نهایی» از حالت Oversize خارج شدند و با عرض، ارتفاع Header و زبان بصری بلوک‌های اصلی یکسان شدند.
- محتوای خروجی نهایی مرکزچین شد.
- سه عملیات دریافت تصویر، دریافت PDF و اشتراک PDF در باکس داخلی منظم و مرکزچین قرار گرفتند؛ در موبایل به‌صورت سه کارت فشرده عمودی و در عرض‌های بزرگ‌تر سه‌ستونه نمایش داده می‌شوند.
- همه تغییرات ظاهری برای Solar و Emergency مشترک هستند.
