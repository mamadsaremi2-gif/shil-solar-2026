# گزارش اصلاح یکپارچه ظاهر صفحات — SHIL V7

## هدف
یکسان‌سازی زبان بصری تمام صفحات مهندسی بدون تغییر منطق محاسبات، مسیرها، داده‌ها یا رویدادهای React.

## اصلاحات اصلی
- تعریف یک مرجع نهایی برای عنوان سکشن‌ها در تمام ساختارهای قدیمی و جدید.
- یکسان‌سازی کارت‌های داده، کارت‌های نتیجه، کارت‌های فرم و کارت‌های خلاصه.
- یکسان‌سازی input، select، textarea و checkbox.
- یکسان‌سازی دکمه‌های تأیید و جلوگیری از بریده‌شدن آن‌ها با Footer.
- تبدیل هشدارهای شناورِ پوشاننده محتوا به بلوک‌های عادی داخل جریان صفحه.
- حذف رنگ و Borderهای متناقض قرمز، بنفش و شفاف از کارت‌های عادی.
- تثبیت رنگ و هندسه Header و Footer.
- یکسان‌سازی فاصله‌ها، Radius، Shadow و عرض محتوا.
- حذف Badgeهای انگلیسی داخل عنوان سکشن‌ها، بدون حذف متن‌های فنی داخل داده‌ها.
- حفظ ظاهر Login و Welcome از این لایه.

## فایل مرجع نهایی
`src/appearance/styles/shil-unified-engineering-design-system-v7.css`

این فایل در آخرین خط `src/main.jsx` ایمپورت شده و باید آخرین CSS باقی بماند.

## محدوده تغییر
- فقط لایه ظاهری اصلاح شده است.
- فایل‌های محاسبات، Store، Engine، API و داده‌های تجهیزات تغییر نکرده‌اند.
- CSSهای قدیمی حذف نشده‌اند تا رفتارهای ساختاری و Responsive صفحه‌ها از بین نرود؛ اما قانون V7 به‌عنوان مرجع نهایی، تضادهای بصری را خنثی می‌کند.
