# گزارش V6.6 — اصلاح اختصاصی صفحه انتخاب مسیر پروژه

- تغییرات فقط به صفحه «مسیر پروژه» محدود شده است.
- پس‌زمینه/Wrapper خاکستری پشت دو کارت اصلی حذف شد.
- کارت‌ها مستقیماً روی بک‌گراند اصلی صفحه قرار گرفتند.
- تمام خطوط این صفحه مشکی و یکدست شدند.
- داده ثابت/راهنما: آبی کم‌رنگ.
- انتخاب و ورودی کاربر: سبز کم‌رنگ.
- انتخاب فعال: سبز پررنگ‌تر با خط مشکی.
- دکمه تأیید: گرادیان آبی–بنفش با خط مشکی.
- هیچ صفحه دیگری تغییر ظاهری نکرده است.
- منطق انتخاب، ذخیره و ناوبری دست‌نخورده باقی مانده است.
