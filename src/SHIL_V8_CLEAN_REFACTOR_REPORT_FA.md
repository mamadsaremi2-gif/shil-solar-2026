# گزارش پاک‌سازی کامل لایه‌های ظاهری SHIL V8

## نتیجه اجرایی

- ورودی اصلی پروژه اکنون فقط **یک فایل CSS پروژه** را بارگذاری می‌کند:
  `appearance/styles/shil-engineering-design-system-v8-clean.css`
- تمام Importهای ظاهری V3، V4، V5، V6 و V7 از `main.jsx` حذف شده‌اند.
- Import قدیمی `shil-engineering-theme-v2.css` از `App.jsx` حذف شده است.
- Importهای محلی `ShilFrame.css` و `EquipmentBankCard.css` حذف شده‌اند تا دوباره وارد Cascade نشوند.
- اسکریپت‌های رفتاری مربوط به کلاس صفحه ورود، خوش‌آمدگویی و جای‌گذاری دکمه تأیید حفظ شده‌اند.
- CSS کتابخانه‌های ثالث مانند AG Grid، React Flow، MapLibre، DatePicker، Calendar و KaTeX همچنان در Component مربوط به خود باقی مانده‌اند؛ این فایل‌ها بخشی از پوسته ظاهری SHIL نیستند و حذف آن‌ها عملکرد کتابخانه را خراب می‌کند.

## وضعیت لایه‌های قدیمی

فایل‌های CSS قدیمی برای قابلیت بازگشت و بررسی تاریخی داخل سورس باقی مانده‌اند، اما دیگر از `main.jsx` یا `App.jsx` بارگذاری نمی‌شوند؛ بنابراین در خروجی Runtime فعال نیستند.

## سیستم طراحی فعال

فایل V8 موارد زیر را به صورت متمرکز کنترل می‌کند:

- Canvas و تصویر پس‌زمینه
- Header و Footer ثابت
- Rail مراحل پروژه
- عنوان تمام سکشن‌ها
- کارت‌ها و پنل‌ها
- Gridهای دو ستونه و Responsive
- Input، Select، Textarea، Checkbox و Radio
- دکمه‌های تأیید
- Alert و Warningهای غیرشناور
- جدول‌ها
- فاصله‌ها، Radius، Border، Shadow و Typography

## محدودیت تست

آرشیو ورودی فقط پوشه `src` را شامل می‌شد و فایل‌های ریشه پروژه مانند `package.json` در اختیار نبود؛ بنابراین Build واقعی Vite/React در این محیط اجرا نشد. صحت ساختاری Importها، وجود فایل‌ها و توازن براکت CSS بررسی شده است.
