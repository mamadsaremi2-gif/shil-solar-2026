# اصلاح ظاهری درگاه ادمین SHIL — Floating Cards / No Parent

تاریخ: 2026-08-10

## هدف
حذف سطح بصری والدهای بزرگ ادمین تا تصویر پس‌زمینه خورشیدی بین و پشت کارت‌ها دیده شود و پنل با زبان طراحی صفحات مهندسی SHIL یکپارچه گردد.

## تغییرات
- حذف background، border، shadow و padding بصری از `shil-admin-panel` و والدهای Command/Review/Analytics/Diagnostics.
- حفظ Wrapperهای React فقط برای ساختار DOM؛ Wrapperها دیگر هیچ سطح رنگی ایجاد نمی‌کنند.
- تبدیل عنوان هر بخش به کارت کوچک مستقل و شناور.
- تبدیل Hero بزرگ ادمین به دو کارت مستقل فشرده (اطلاعات + خروج).
- قرار گرفتن Tabها مستقیماً روی پس‌زمینه و تبدیل هر Tab به کارت مستقل روشن.
- حذف رنگ بنفش از حالت Active و جایگزینی با طیف سفید/آبی مهندسی SHIL.
- استفاده از کارت‌های روشن نیمه‌شفاف برای KPI، Timeline، Review، Equipment CMS، Diagnostics، Snapshot و سایر داده‌ها.
- حفظ سطح روشن فقط داخل آکاردئون باز، نه پشت کل مجموعه کارت‌ها.
- فاصله موبایل از دیواره‌ها 8px و فاصله کارت‌ها 5–7px.
- کاهش ارتفاع و فونت کارت‌های موبایل برای تراکم بیشتر اطلاعات.
- اصلاح کنتراست متن‌ها روی کارت‌های روشن.

## نتیجه
تصویر زمینه خورشیدی اکنون بین کارت‌های پنل ادمین قابل مشاهده است و هیچ والد بزرگ خاکستری/تیره پشت مجموعه کارت‌ها وجود ندارد.
