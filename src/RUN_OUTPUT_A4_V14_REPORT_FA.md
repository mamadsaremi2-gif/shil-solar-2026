# گزارش آپدیت V14 — خروجی نهایی SHIL

این نسخه ادامه V13 است و اصلاحات صفحه «اجرا و خروجی نهایی» را برای هر دو مسیر خورشیدی و برق اضطراری تکمیل می‌کند.

## اصلاحات اصلی
- تثبیت قرارداد نمایش مقادیر مهندسی به شکل «عدد سپس واحد» در UI و A4/PDF/PNG/Share با Unicode isolation.
- محدودیت اعشار در همان formatter مشترک حفظ شده است.
- اصلاح جای لوگو در هدر A4 و جلوگیری از خروج آن از باکس.
- اصلاح جای شماره‌های 01 تا 04 و نگه‌داشتن آن‌ها داخل کادر عنوان هر بخش.
- تقویت سلسله‌مراتب تایپوگرافی: عنوان/label کوچک‌تر و کم‌رنگ‌تر، جواب اصلی تیره‌تر و Bold.
- تکمیل Mapping حفاظت و کابل‌های Solar از خروجی `unifiedPvEngine.protection`؛ UI دیگر مقدار حفاظت را دوباره محاسبه نمی‌کند.
- پشتیبانی از خروجی‌های موتور با نام‌گذاری snake_case برای کابل‌ها (`design_current_A`, `length_m`, ...).
- اصلاح رشته‌های خام تجهیزات A4 تا توان، انرژی و ولتاژ نیز از formatter مشترک استفاده کنند.
- انتخاب منبع داده با `firstNonEmptyObject` تا آبجکت خالی یک منبع قدیمی مانع خواندن خروجی واقعی موتور مرکزی نشود.
