# گزارش اصلاحات SHIL Phase 2.4

- کارت‌های پروژه در صفحات «در حال اجرا»، «نهایی» و «آرشیو» با اندازه و رنگ کارت‌های صفحه اصلی مدیریت پروژه‌ها یکسان شدند.
- ارتفاع کارت بسته روی موبایل حدود 44px تثبیت شد.
- فاصله بین کارت‌ها 6px و فاصله از دیواره موبایل 8 تا 10px تنظیم شد.
- والد بصری بزرگ پشت لیست پروژه‌ها حذف شد؛ workspace و list اکنون کاملاً transparent هستند و خود کارت‌ها مستقیماً روی تصویر پس‌زمینه می‌نشینند.
- رنگ‌بندی کارت‌ها از پالت روشن مهندسی SHIL استفاده می‌کند؛ سبز فقط برای وضعیت نهایی و خاکستری روشن برای آرشیو باقی مانده است.
- جزئیات آکاردئونی نیز فشرده‌تر شده و باز شدن یک پروژه فقط همان کارت را بزرگ می‌کند.
- Toolbar و عنوان لیست مستقل هستند و هیچ قاب/پنل یکپارچه بزرگی دور مجموعه کارت‌ها ایجاد نمی‌کنند.
- تغییرات PWA و آیکون نسخه Phase 2.3 حفظ شده‌اند.
