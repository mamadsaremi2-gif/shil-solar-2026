SHIL V25.2 Stage 2 - Admin UX & Stability
==========================================

اصلاحات این مرحله بر اساس تست لوکال Stage 1:

1) بانک مصرف‌کننده‌ها
- Toolbar جستجو/فیلتر/افزودن از حالت هم‌پوشان خارج شد.
- آمار در Grid مستقل و فشرده قرار گرفت.
- دسته‌ها آکاردئونی، تک‌لایه و بدون والد خاکستری باقی ماندند.
- کارت‌های مصرف‌کننده کوتاه و Mobile-first شدند.

2) بانک تجهیزات
- فضای خالی بالای CMS و Sticky slab حذف شد.
- جستجو، وضعیت، نوع تجهیز و افزودن تجهیز در Toolbar کنترل‌شده قرار گرفتند.
- آمار کل/فعال/منتشرشده/نیازمند اصلاح مستقل شد.
- عنوان گروه‌ها به شکل خوانای «عنوان / تعداد رکورد / تعداد دسته» تنظیم شد.
- کارت تجهیز بسته فشرده و جزئیات فقط با بازکردن نمایش داده می‌شود.
- تداخل عنوان فارسی، توان، وضعیت و کلید +/- اصلاح شد.

3) مدیریت پروژه‌ها
- کارت بسته کوتاه و فقط کاربر + مسیر پروژه است.
- جزئیات اصلی پروژه فشرده شد.
- بخش‌های اطلاعات پروژه، محیط، ورودی، تنظیمات، چکیده، نتایج و AI به Accordion داخلی تبدیل شدند.
- Labelهای متداول خام به فارسی تبدیل شدند.
- running و Statusهای رایج به فارسی نمایش داده می‌شوند.
- تاریخ/ساعت با فرمت فارسی ثابت نمایش داده می‌شود.
- شناسه فنی Project ID در Accordion جدا قرار گرفت.
- سه عمل حذف / انتقال به سناریو / اشتراک حفظ شدند.

4) RLS و خطای Backend
- Migration جدید SHIL_V25_2_STAGE2_ADMIN_RLS.sql اضافه شد.
- دسترسی صریح approved admin به shil_app_data و shil_records اضافه می‌شود.
- ready_scenarios در Public Read باقی می‌ماند.
- خطاهای RLS/Auth/Network در UI به پیام فارسی کنترل‌شده تبدیل می‌شوند.
- پس از انتقال پروژه به سناریو، شکست Sync متادیتای ثانویه پروژه دیگر انتقال موفق سناریو را خراب نمی‌کند.

5) نمای کلی Admin
- بنفش Legacy با override نهایی حذف می‌شود.
- Readiness و KPIها فشرده‌تر و با گرادیان مرجع SHIL هستند.
- Parentهای خاکستری و Shadow/Glow اضافی خنثی شدند.
- پنل‌های پایین Overview در Grid مینیمال باقی می‌مانند.

6) ساختار CSS
- Import قدیمی shil-admin-v21-comprehensive.css از AdminDashboard حذف شد.
- فایل نهایی Stage 2 بعد از V24 و Stage 1 لود می‌شود:
  src/styles/shil-v25-2-stage2-admin-ux.css

قبل از تست انتقال سناریو، Migration زیر یک بار در Supabase اجرا شود:
  supabase/SHIL_V25_2_STAGE2_ADMIN_RLS.sql
